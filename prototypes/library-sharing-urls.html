Throwaway prototype for the Game Backlog Tracker. Each user picks whether their library is Public or Private (default: Private). This demo lets you compare three website layouts and check, for every kind of visitor, what they actually get on each page. Watch for anything that feels wrong, e.g. a private library leaking, or a link that behaves unexpectedly after a setting changes.
